# tests

**Purpose:** This folder contains the automated testing suites for the SteamSync solution. It provides unit and integration tests to validate the correctness, stability, and reliability of the application's core functionality.

**Key Components:**
- `SteamSync.Core.Tests`: An xUnit-based test project containing comprehensive test fixtures for game detectors, Steam VDF parsing, AppID generation, title sanitization, and database operations.

**Dependencies:** Directly references and tests the projects in `src/SteamSync.Core`.
