## "Where do I look for a duplicate?"

Start at:

1. GameDetectionService title GroupBy
2. GameRepository Title + Platform lookup
3. detector-specific IDs/normalization
4. post-SteamGridDB title resolution in GameListViewModel

## "Where do I look when artwork is wrong?"

1. DetectedGame.Title
2. TitleSanitizer
3. ArtworkManager.ResolveGameTitleAsync
4. SteamGridDbClient.SearchGamesAsync
5. ArtworkManager.FetchAndSaveArtworkAsync

## "Where do I look when a Steam shortcut is wrong?"

1. DetectedGame fields
2. AppIdGenerator
3. SteamInjectorService
4. SteamShortcut
5. ShortcutsVdfWriter
6. SteamPathResolver
7. Steam process state

## "Where do I look when Force Sync fails?"

1. SteamProcessManager.IsSteamRunning
2. ForceKillAndWaitAsync
3. SteamPathResolver.GetSteamExePath
4. SteamInjectorService.ForceSyncAsync
5. log file in %AppData%\SteamSync\steamsync.log

## General navigation technique

Search by symbol rather than by filename.

Useful search targets:

- class name
- method name
- property name
- command name generated by CommunityToolkit
- model field
- log category

Then follow the call graph outward:

caller → implementation → dependencies → side effect.

## Checkpoint

Take an unfamiliar feature and answer:

1. What is the UI entry point?
2. Which ViewModel owns it?
3. Which Core service does it call?
4. Which model crosses the boundary?
5. What external side effect happens?
