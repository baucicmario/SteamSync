# Worker 5: EA App Executable Generator

## Objective
Implement a solution that takes all uninstalled games from the EA App (formerly Origin) and generates a dummy `.exe` file for each one. When executed, this `.exe` must safely trigger the EA install prompt, with a fallback if the EA App is corrupted.

## Context & Requirements
- **Target:** EA App (`Platform = 'EA'`).
- **Command Logic:** The EA App relies heavily on OS protocol handlers. If the registry keys (`HKCR:\ea` or `HKCR:\origin2`) are missing, the launcher ignores all commands.
- **Execution Logic to Embed:** 
  1. Check Windows Registry to ensure `HKCR:\ea` or `HKCR:\origin2` exists.
  2. If missing: Display a `MessageBox` warning the user that their EA App registry is broken and they must run the EA "App Recovery" tool.
  3. If present: Run the following command:
  ```csharp
  Process.Start(new ProcessStartInfo {
      FileName = $"ea://launch/{OfferID}",
      UseShellExecute = true
  });
  ```
- **Task:** Compile dummy executables for uninstalled EA games that include this registry check and execution logic.
- **Steam Syncing:** After generating the dummy `.exe`, sync the game to Steam using this `.exe` as the target shortcut. You must pull the customized (grayscaled) images from the internal image cache (e.g., `SteamSync\Cache\UninstalledImages\{Platform}\{GameID}_cover.jpg`) generated by **Worker 1**, and apply them to the new Steam shortcut's official AppID grid files. This ensures it appears as a clear "Download Game" link in the Steam library.
