# Worker 6: Battle.net Executable Generator

## Objective
Implement a solution that takes all uninstalled games from Battle.net and generates a dummy `.exe` file for each one. When executed, this `.exe` must automatically focus the Battle.net client on the game's page.

## Context & Requirements
- **Target:** Battle.net (`Platform = 'Battle.net'`).
- **Command Logic:** Battle.net does not have an auto-install flag. You must launch the executable directly with the `--game` argument to focus the client.
- **Execution Command to Embed:** 
  ```csharp
  string bnetPath = /* Resolve from Registry: HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\Battle.net -> InstallLocation */ + "\\Battle.net.exe";
  Process.Start(bnetPath, $"--game={GameUID}");
  ```
- **Task:** Compile dummy executables for uninstalled Battle.net games containing this logic. The executable must dynamically resolve the path from the registry at runtime.
- **Steam Syncing:** After generating the dummy `.exe`, sync the game to Steam using this `.exe` as the target shortcut. You must pull the customized (grayscaled) images from the internal image cache (e.g., `SteamSync\Cache\UninstalledImages\{Platform}\{GameID}_cover.jpg`) generated by **Worker 1**, and apply them to the new Steam shortcut's official AppID grid files. This ensures it appears as a clear "Download Game" link in the Steam library.
