# Worker 7: Rockstar Games Launcher Executable Generator

## Objective
Implement a solution that takes all uninstalled games from the Rockstar Games Launcher and generates a dummy `.exe` file for each one. When executed, this `.exe` must automatically trigger the Rockstar install prompt.

## Context & Requirements
- **Target:** Rockstar Games Launcher (`Platform = 'Rockstar'`).
- **Command Logic:** Uses a direct command-line argument to the launcher executable.
- **Execution Command to Embed:** 
  ```csharp
  string rsPath = /* Resolve from Registry: HKLM:\SOFTWARE\WOW6432Node\Rockstar Games\Launcher -> InstallFolder */ + "\\Launcher.exe";
  Process.Start(rsPath, $"-installTitle {TitleID}");
  ```
- **Task:** Compile dummy executables for uninstalled Rockstar games containing this logic. The executable must dynamically resolve the path from the registry at runtime.
- **Steam Syncing:** After generating the dummy `.exe`, sync the game to Steam using this `.exe` as the target shortcut. You must pull the customized (grayscaled) images from the internal image cache (e.g., `SteamSync\Cache\UninstalledImages\{Platform}\{GameID}_cover.jpg`) generated by **Worker 1**, and apply them to the new Steam shortcut's official AppID grid files. This ensures it appears as a clear "Download Game" link in the Steam library.
