# Worker 3: GOG Galaxy Executable Generator

## Objective
Implement a solution that takes all uninstalled games from GOG Galaxy and generates a dummy `.exe` file for each one. When executed, this `.exe` must automatically trigger the GOG Galaxy installation prompt.

## Context & Requirements
- **Target:** GOG Galaxy (`Platform = 'GOG'`).
- **Command Logic:** GOG requires a two-step process to reliably open the install prompt. First, you run the CLI install command, then immediately force the UI to focus on it via a URI.
- **Execution Commands to Embed:** 
  ```csharp
  // Step 1: Trigger background install
  string gogClientPath = /* Resolve from Registry: HKLM:\SOFTWARE\WOW6432Node\GOG.com\GalaxyClient\paths -> client */ + "\\GalaxyClient.exe";
  Process.Start(gogClientPath, $"/command=installGame /gameId={GameID}");
  
  // Step 2: Focus UI
  Process.Start(new ProcessStartInfo {
      FileName = $"goggalaxy://openGameView/{GameID}",
      UseShellExecute = true
  });
  ```
- **Task:** Write a utility to dynamically compile dummy executables for uninstalled GOG games containing this logic. The executable must read the registry path dynamically at runtime.
- **Steam Syncing:** After generating the dummy `.exe`, sync the game to Steam using this `.exe` as the target shortcut. You must pull the customized (grayscaled) images from the internal image cache (e.g., `SteamSync\Cache\UninstalledImages\{Platform}\{GameID}_cover.jpg`) generated by **Worker 1**, and apply them to the new Steam shortcut's official AppID grid files. This ensures it appears as a clear "Download Game" link in the Steam library.
