# Worker 8: Xbox / Windows Store Executable Generator

## Objective
Implement a solution that takes all uninstalled games from the Xbox app / Windows Store and generates a dummy `.exe` file for each one. When executed, this `.exe` must open the game's product page.

## Context & Requirements
- **Target:** Xbox / Windows Store (`Platform = 'Xbox'`).
- **Command Logic:** The Xbox app does not expose a reliable URI for specific game pages. The fallback is to use the native Windows Store protocol.
- **Execution Command to Embed:** 
  ```csharp
  Process.Start(new ProcessStartInfo {
      FileName = $"ms-windows-store://pdp/?productid={ProductID}",
      UseShellExecute = true
  });
  ```
- **Task:** Compile dummy executables for uninstalled Xbox games containing this logic so the user can easily install them via the Microsoft Store.
- **Steam Syncing:** After generating the dummy `.exe`, sync the game to Steam using this `.exe` as the target shortcut. You must pull the customized (grayscaled) images from the internal image cache (e.g., `SteamSync\Cache\UninstalledImages\{Platform}\{GameID}_cover.jpg`) generated by **Worker 1**, and apply them to the new Steam shortcut's official AppID grid files. This ensures it appears as a clear "Download Game" link in the Steam library.
