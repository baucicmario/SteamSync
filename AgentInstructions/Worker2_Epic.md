# Worker 2: Epic Games Executable Generator

## Objective
Implement a solution that takes all uninstalled games from the Epic Games Store and generates a dummy `.exe` file for each one. When executed by Steam/SteamSync, this `.exe` must automatically trigger the Epic Games store page to prompt the user to download the game.

## Context & Requirements
- **Target:** Epic Games Store (`Platform = 'Epic'`).
- **Command Logic:** Epic's `?action=install` URI is bugged. The robust fallback is to route the user to the specific game's store page using its `StoreSlug` (e.g., `hogwarts-legacy`).
- **Execution Command to Embed:** 
  ```csharp
  Process.Start(new ProcessStartInfo {
      FileName = $"com.epicgames.launcher://store/p/{StoreSlug}",
      UseShellExecute = true
  });
  ```
- **Task:** Write a C# utility (using Roslyn `CSharpCodeProvider` or standard .NET compilation) that generates a small Windows executable for each uninstalled Epic game. The executable should silently run the command above and exit.
- **Steam Syncing:** After generating the dummy `.exe`, sync the game to Steam using this `.exe` as the target shortcut. You must pull the customized (grayscaled) images from the internal image cache (e.g., `SteamSync\Cache\UninstalledImages\{Platform}\{GameID}_cover.jpg`) generated by **Worker 1**, and apply them to the new Steam shortcut's official AppID grid files. This ensures it appears as a clear "Download Game" link in the Steam library.
